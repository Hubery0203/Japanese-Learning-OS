# N5 Particles

## は (Topic)

Example:
- 日本語は面白いです。

Meaning:
- Speaking about Japanese, it is interesting.

## が (Preference / subject)

Example:
- 日本語が好きです。
- 寿司が好きです。

## を (Object)

Example:
- 寿司を食べます。
- 水を飲みます。

## で (Place of action)

Example:
- 日本で日本語を勉強します。

## へ (Direction)

Example:
- 東京へ行きます。

## の (Connection)

Example:
- 日本語の勉強
