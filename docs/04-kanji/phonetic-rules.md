# 汉字读音：音読、訓読与音变规则

## 音読（おんよみ）与訓読（くんよみ）

**音读**来自汉字传入日本时对汉语读音的吸收，常用于汉字复合词。例：<ruby>学生<rt>がくせい</rt></ruby>、<ruby>日本<rt>にほん</rt></ruby>、<ruby>電話<rt>でんわ</rt></ruby>。同一个字可能有多个音读，如 生 可读 せい、しょう。

**训读**是用日本本土词义来读汉字，常用于单个汉字加假名词尾。例：<ruby>山<rt>やま</rt></ruby>、<ruby>読<rt>よ</rt></ruby>む、<ruby>新<rt>あたら</rt></ruby>しい。训读能帮助你理解词干与活用词尾：<ruby>書<rt>か</rt></ruby>く、<ruby>書<rt>か</rt></ruby>かない、<ruby>書<rt>か</rt></ruby>いた。

## 什么时候用音读，什么时候用训读

| 场景 | 常见读法 | 例子 |
|---|---|---|
| 两个或多个汉字组成的熟语 | 多为音读 | <ruby>学校<rt>がっこう</rt></ruby>、<ruby>電車<rt>でんしゃ</rt></ruby>、<ruby>勉強<rt>べんきょう</rt></ruby> |
| 单个汉字表示自然物或日常词 | 多为训读 | <ruby>水<rt>みず</rt></ruby>、<ruby>火<rt>ひ</rt></ruby>、<ruby>人<rt>ひと</rt></ruby> |
| 汉字 + 送り仮名 | 多为训读 | <ruby>高<rt>たか</rt></ruby>い、<ruby>食<rt>た</rt></ruby>べる、<ruby>走<rt>はし</rt></ruby>る |
| 专有名词、人名、地名 | 需要单独确认 | <ruby>東京<rt>とうきょう</rt></ruby>、<ruby>日本橋<rt>にほんばし</rt></ruby> |

## 連濁（れんだく）：后项浊化

连浊指复合词中第二个词开头的清音变成浊音。它常发生在日语本土词复合中，使发音更顺滑。

| 原词 | 复合词 | 说明 |
|---|---|---|
| <ruby>手<rt>て</rt></ruby> + <ruby>紙<rt>かみ</rt></ruby> | <ruby>手紙<rt>てがみ</rt></ruby> | か → が |
| <ruby>花<rt>はな</rt></ruby> + <ruby>火<rt>ひ</rt></ruby> | <ruby>花火<rt>はなび</rt></ruby> | ひ → び |
| <ruby>山<rt>やま</rt></ruby> + <ruby>川<rt>かわ</rt></ruby> | <ruby>山川<rt>やまがわ</rt></ruby> | か → が，在姓氏或地名中也常见 |
| <ruby>人<rt>ひと</rt></ruby> + <ruby>々<rt>びと</rt></ruby> | <ruby>人々<rt>ひとびと</rt></ruby> | 重复符号后读音变化 |

并非所有复合词都会连浊。外来语、部分汉语词、已有浊音阻塞的词，或固定习惯读法可能阻止连浊。因此学习时应把词的读音和词义一起记。

## 促音化（そくおんか）：变成小 っ

促音化指词中出现小 っ，使后续辅音停顿一拍后爆发。它常见于音读复合词中，尤其当前字以 く、つ、ち 等收尾感较强的音接无声辅音时。

| 组成 | 结果 | 说明 |
|---|---|---|
| 学（がく）+ 校（こう） | <ruby>学校<rt>がっこう</rt></ruby> | く + こ → っこ |
| 日（にち）+ 記（き） | <ruby>日記<rt>にっき</rt></ruby> | ち + き → っき |
| 一（いち）+ 分（ぷん） | <ruby>一分<rt>いっぷん</rt></ruby> | ち + ふ/ぷ → っぷ |
| 切（せつ）+ 手（て） | <ruby>切手<rt>きって</rt></ruby> | つ + て → って；读音和字面音不同 |

## 读音学习策略

1. 复合词优先用整词记忆，不要逐字机械拼读。
2. 每个汉字至少记录一个高频音读和一个高频训读。
3. 碰到连浊或促音化时，在笔记中标出变化来源，例如 紙→がみ、学→がっ。
4. 用朗读检查拍数：<ruby>学校<rt>がっこう</rt></ruby> 是四拍（が・っ・こ・う），不是两拍。
