# 五十音：平假名、片假名与发音规则

五十音（五十音図）是日语发音和书写的入口。平假名多用于语法词尾、助词和本土词，片假名多用于外来语、拟声拟态词、强调和专有名词。每格写法为 **平假名 / 片假名 / romaji**。

## 拗音（Yōon）

拗音由 **い段假名 + 小 ゃ/ゅ/ょ** 组成，占一个拍（mora），如 きゃ 是一拍，不是 き + や 两拍。

## 发音规则与例词

### 促音 `っ / ッ`

小 っ 表示停顿一拍，后面的辅音要“憋住再放出”。例：きって（切手，kitte）、がっこう（学校，gakkō）、サッカー（sakkā）。记忆法：看到小 っ，就在心里数一个无声拍。

### 长音

平假名中常用元音延长：おかあさん（母亲）、おにいさん（哥哥）、せんせい（先生，读作 sensee）、おとうさん（父亲，读作 otōsan）。片假名中常用长音符号 `ー`：ケーキ（cake）、コーヒー（coffee）、スーパー（supermarket）。长音必须占一拍，长度错了可能改变词义：おばさん（阿姨） vs おばあさん（奶奶）。

### 拨音 `ん / ン`

`ん` 单独占一拍，读音随环境变化：在 ま/ば/ぱ 前接近 m，如 しんぶん；在 か/が 前接近 ŋ，如 まんが；在元音或半元音前带鼻化过渡，如 ほんを。不要把 ん 和前一个元音合并成一个音。

### 元音弱化与拍感

す、し 中的 u/i 在无声辅音之间或句末常弱化，例如 です、します 中的 す 常听起来很轻。日语节奏按拍计算：にほんご 是四拍（に・ほ・ん・ご），とうきょう 也是四拍（と・う・きょ・う）。

## 学习建议

- 先按行背，再按段练：あかさたな、はまやらわ。
- 片假名要和外来语一起记：ホテル、メール、コンビニ。
- 每天手写 5 行，并朗读例词，避免只“认得”但写不出。
