# N5 综合自测蓝图

旧版仓库只有分项标题，没有题目或答案。此页把它整理为待编写的评估蓝图，不虚构分数或题目。

## 评估分项

1. **语法**：助词、动词活用、核心句型；覆盖已学课程并含新语境造句。
2. **词汇**：从经校对的 N5 词表抽取识别与主动回忆题。
3. **汉字**：读音、词义与常见词语搭配。
4. **阅读**：短篇生活文本，检查信息定位与语法理解。

## 出题与判定规则

- 每题关联一个课程或知识点 ID。
- 题目、答案和评分标准分开保存；用户作答前不显示答案。
- 记录正确率和错误类型，不用单次自测代替课程掌握证据。
- 正式启用前补齐题目、答案、出处和人工校对记录。
