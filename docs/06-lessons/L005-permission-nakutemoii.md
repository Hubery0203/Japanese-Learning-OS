## 2. 〜なくてもいい

- **语法接续**：动词ない形去 い + くてもいい；い形容词くなくてもいい；名词/な形容词でなくてもいい。
- **核心含义**：不……也可以；没有必要……。
- **详细语境/注意事项**：表示许可或免除义务。比 〜なくてもかまわない 更口语、更温和。
- **例句**：
  - <ruby>明日<rt>あした</rt></ruby>は<ruby>早<rt>はや</rt></ruby>く<ruby>来<rt>こ</rt></ruby>なくてもいいです。明天不用早来。
  - <ruby>全部<rt>ぜんぶ</rt></ruby>を<ruby>覚<rt>おぼ</rt></ruby>えなくてもいいですが、<ruby>例文<rt>れいぶん</rt></ruby>は<ruby>読<rt>よ</rt></ruby>んでください。不用全记住，但请读例句。
