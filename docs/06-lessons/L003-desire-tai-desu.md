# 用「たいです」表达愿望

- **ID**: `lesson_003`
- **级别**: N5
- **主题**: 动词ます形词干 + たいです
- **前置知识**: `lesson_002`（ます形）
- **关联知识点**: `grammar_034`
- **预计用时**: 10 分钟

## 学习目标

能用「たいです」表达自己想做的事，并正确保留动作对象助词「を」。

## 讲解

将动词ます形去掉「ます」，再加「たいです」：食べます→食べたいです、行きます→行きたいです。表示“想做……”。「たい」按い形容词活用：食べたくないです（不想吃）。

当对象助词「を」后面接「たいです」时，日常表达中常保留「を」；「が」也可能用于突出想要的对象或能力、偏好语境，初学时先按动词原本的对象关系造句。

## 例句

| 日语 | 中文 |
|---|---|
| 寿司を食べたいです。 | 我想吃寿司。 |
| 日本へ行きたいです。 | 我想去日本。 |
| 東京で日本語を勉強したいです。 | 我想在东京学习日语。 |
| 今日は出かけたくないです。 | 今天不想出门。 |

## 易错点

- 不要在「ます」后直接接「たい」：× 食べますたい。
- 「たい」前接ます形词干：食べます→食べたい。
- 地点助词和动作对象助词作用不同：東京**で**（动作地点）、日本語**を**（学习对象）。

## 练习

1. 把「飲みます」改成“想喝”。
2. 翻译：我想在日本看电影。
3. 把「食べたいです」改成“不想吃”。
