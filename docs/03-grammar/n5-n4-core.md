# N5/N4 核心语法卡片

每张卡片包含接续、核心含义、语境注意和例句。例句中的汉字均配有 `<ruby>` 假名标注。

## 1. 〜てはいけない

- **语法接续**：动词て形 + はいけない / はだめだ。
- **核心含义**：不可以……；禁止……。
- **详细语境/注意事项**：表示规则、纪律或强烈劝阻。对上级直接使用可能显得生硬，可改为 〜ないでください。
- **例句**：
  - <ruby>教室<rt>きょうしつ</rt></ruby>で<ruby>大<rt>おお</rt></ruby>きな<ruby>声<rt>こえ</rt></ruby>で<ruby>話<rt>はな</rt></ruby>してはいけません。不能在教室里大声说话。
  - この<ruby>薬<rt>くすり</rt></ruby>を<ruby>酒<rt>さけ</rt></ruby>と<ruby>一緒<rt>いっしょ</rt></ruby>に<ruby>飲<rt>の</rt></ruby>んではいけません。不能把这个药和酒一起喝。

## 2. 〜なくてもいい

- **语法接续**：动词ない形去 い + くてもいい；い形容词くなくてもいい；名词/な形容词でなくてもいい。
- **核心含义**：不……也可以；没有必要……。
- **详细语境/注意事项**：表示许可或免除义务。比 〜なくてもかまわない 更口语、更温和。
- **例句**：
  - <ruby>明日<rt>あした</rt></ruby>は<ruby>早<rt>はや</rt></ruby>く<ruby>来<rt>こ</rt></ruby>なくてもいいです。明天不用早来。
  - <ruby>全部<rt>ぜんぶ</rt></ruby>を<ruby>覚<rt>おぼ</rt></ruby>えなくてもいいですが、<ruby>例文<rt>れいぶん</rt></ruby>は<ruby>読<rt>よ</rt></ruby>んでください。不用全记住，但请读例句。

## 3. 〜ほうがいい

- **语法接续**：动词た形 + ほうがいい；动词ない形 + ほうがいい。
- **核心含义**：最好……；建议……。
- **详细语境/注意事项**：带有“为你好”的建议语气。否定建议用 〜ないほうがいい。
- **例句**：
  - <ruby>風邪<rt>かぜ</rt></ruby>ですから、<ruby>早<rt>はや</rt></ruby>く<ruby>寝<rt>ね</rt></ruby>たほうがいいです。因为感冒了，最好早点睡。
  - <ruby>試験<rt>しけん</rt></ruby>の<ruby>前<rt>まえ</rt></ruby>に<ruby>新<rt>あたら</rt></ruby>しい<ruby>文法<rt>ぶんぽう</rt></ruby>を<ruby>増<rt>ふ</rt></ruby>やさないほうがいいです。考试前最好不要增加新语法。

## 4. 〜ようになる

- **语法接续**：动词辞书形/ない形 + ようになる。
- **核心含义**：变得会……；逐渐形成某种状态。
- **详细语境/注意事项**：强调能力、习惯或状态的变化，不用于一次性的瞬间决定。
- **例句**：
  - <ruby>毎日<rt>まいにち</rt></ruby><ruby>練習<rt>れんしゅう</rt></ruby>して、<ruby>漢字<rt>かんじ</rt></ruby>が<ruby>読<rt>よ</rt></ruby>めるようになりました。每天练习后，变得能读汉字了。
  - <ruby>最近<rt>さいきん</rt></ruby>、<ruby>夜<rt>よる</rt></ruby><ruby>遅<rt>おそ</rt></ruby>く<ruby>食<rt>た</rt></ruby>べないようになりました。最近变得不在深夜吃东西了。

## 5. 〜ことにする

- **语法接续**：动词辞书形/ない形 + ことにする。
- **核心含义**：决定……。
- **详细语境/注意事项**：强调说话人主动做出的决定。若是外部安排，用 〜ことになる。
- **例句**：
  - <ruby>来月<rt>らいげつ</rt></ruby>から<ruby>日本語<rt>にほんご</rt></ruby>の<ruby>日記<rt>にっき</rt></ruby>を<ruby>書<rt>か</rt></ruby>くことにしました。我决定从下个月开始写日语日记。
  - <ruby>平日<rt>へいじつ</rt></ruby>はゲームをしないことにします。我决定工作日不玩游戏。

## 6. 〜ために / 〜ように

- **语法接续**：动词辞书形 + ために；名词 + のために；可能形/ない形 + ように。
- **核心含义**：为了……。
- **详细语境/注意事项**：ために 常用于意志动词和明确目的；ように 常用于能力、状态、非意志目标。
- **例句**：
  - <ruby>大学<rt>だいがく</rt></ruby>に<ruby>入<rt>はい</rt></ruby>るために、<ruby>毎日<rt>まいにち</rt></ruby><ruby>勉強<rt>べんきょう</rt></ruby>しています。为了进大学，我每天学习。
  - <ruby>忘<rt>わす</rt></ruby>れないように、ノートに<ruby>書<rt>か</rt></ruby>いておきます。为了不忘记，我先写在笔记本上。

## 7. 〜てから

- **语法接续**：动词て形 + から。
- **核心含义**：……之后再……。
- **详细语境/注意事项**：强调前项完成后才发生后项，顺序感比单纯て形更强。
- **例句**：
  - <ruby>宿題<rt>しゅくだい</rt></ruby>をしてから、<ruby>映画<rt>えいが</rt></ruby>を<ruby>見<rt>み</rt></ruby>ます。做完作业后看电影。
  - <ruby>先生<rt>せんせい</rt></ruby>に<ruby>聞<rt>き</rt></ruby>いてから、<ruby>答<rt>こた</rt></ruby>えを<ruby>書<rt>か</rt></ruby>きます。问老师之后再写答案。

## 8. 〜たり〜たりする

- **语法接续**：动词た形 + り、动词た形 + りする。
- **核心含义**：列举若干动作；有时……有时……。
- **详细语境/注意事项**：不是完整列举，而是举例说明一类活动。结尾通常要有 する。
- **例句**：
  - <ruby>週末<rt>しゅうまつ</rt></ruby>は<ruby>本<rt>ほん</rt></ruby>を<ruby>読<rt>よ</rt></ruby>んだり、<ruby>散歩<rt>さんぽ</rt></ruby>したりします。周末读书、散步之类。
  - <ruby>授業<rt>じゅぎょう</rt></ruby>では<ruby>文法<rt>ぶんぽう</rt></ruby>を<ruby>練習<rt>れんしゅう</rt></ruby>したり、<ruby>会話<rt>かいわ</rt></ruby>をしたりします。课上会练语法、做会话等。

## 9. 〜かもしれない

- **语法接续**：普通形 + かもしれない；名词/な形容词词干 + かもしれない。
- **核心含义**：也许……；可能……。
- **详细语境/注意事项**：表示较低把握的推测，比 でしょう 更不确定。
- **例句**：
  - <ruby>午後<rt>ごご</rt></ruby>から<ruby>雨<rt>あめ</rt></ruby>が<ruby>降<rt>ふ</rt></ruby>るかもしれません。下午可能会下雨。
  - この<ruby>問題<rt>もんだい</rt></ruby>はN4の<ruby>試験<rt>しけん</rt></ruby>に<ruby>出<rt>で</rt></ruby>るかもしれません。这个问题可能会出现在 N4 考试中。

## 10. 〜と思う

- **语法接续**：普通形 + と思う。
- **核心含义**：我认为……；我想……。
- **详细语境/注意事项**：用于表达个人判断。引用别人想法时用 〜と思っています 或 〜と言っています 更清楚。
- **例句**：
  - <ruby>日本語<rt>にほんご</rt></ruby>の<ruby>発音<rt>はつおん</rt></ruby>は<ruby>拍<rt>はく</rt></ruby>が<ruby>大切<rt>たいせつ</rt></ruby>だと<ruby>思<rt>おも</rt></ruby>います。我认为日语发音中拍很重要。
  - <ruby>彼<rt>かれ</rt></ruby>はもう<ruby>駅<rt>えき</rt></ruby>に<ruby>着<rt>つ</rt></ruby>いたと<ruby>思<rt>おも</rt></ruby>います。我想他已经到车站了。

## 11. 〜ながら

- **语法接续**：动词ます形去 ます + ながら。
- **核心含义**：一边……一边……。
- **详细语境/注意事项**：前后动作通常由同一主体同时进行；主要动作一般在后项。
- **例句**：
  - <ruby>音楽<rt>おんがく</rt></ruby>を<ruby>聞<rt>き</rt></ruby>きながら、<ruby>単語<rt>たんご</rt></ruby>を<ruby>覚<rt>おぼ</rt></ruby>えます。一边听音乐一边背单词。
  - <ruby>歩<rt>ある</rt></ruby>きながらスマホを<ruby>見<rt>み</rt></ruby>ないでください。请不要边走边看手机。

## 12. 〜そうだ（样态）

- **语法接续**：い形容词去 い + そうだ；な形容词词干 + そうだ；动词ます形去 ます + そうだ。
- **核心含义**：看起来……；似乎要……。
- **详细语境/注意事项**：表示根据外观或迹象作出的判断。いい→よさそう、ない→なさそう。
- **例句**：
  - このケーキは<ruby>甘<rt>あま</rt></ruby>そうです。这个蛋糕看起来很甜。
  - <ruby>空<rt>そら</rt></ruby>が<ruby>暗<rt>くら</rt></ruby>くなりました。<ruby>雨<rt>あめ</rt></ruby>が<ruby>降<rt>ふ</rt></ruby>りそうです。天空变暗了，看起来要下雨。
