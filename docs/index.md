# 日本語学習 Database

欢迎来到一套可直接阅读的日语学习知识库。本库按照「文字 → 词形变化 → 核心语法 → 汉字读音 → 工具资源」的顺序组织，适合从五十音进入 JLPT N5/N4 的学习者。

## 学习路线

1. **五十音与发音**：先掌握平假名、片假名、浊音、半浊音、拗音以及促音、长音、拨音。
2. **动词活用**：理解五段、一段、不规则动词的词尾变化，建立看见词尾就能判断活用的能力。
3. **N5/N4 核心语法**：用接续规则和真实例句掌握常见表达。
4. **汉字读音规律**：了解音读、训读以及连浊、促音化等读音变化。
5. **外部资源**：配合词典、音调工具和简易新闻进行输入训练。

> 建议每次学习一个小节，并把例句大声读出三遍：第一遍看假名，第二遍看汉字，第三遍尝试不看中文翻译。
