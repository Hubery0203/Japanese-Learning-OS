# 高价值日语学习资源

## 发音与音调

- [OJAD - Online Japanese Accent Dictionary](https://www.gavo.t.u-tokyo.ac.jp/ojad/)：东京大学相关项目，适合查询动词活用后的音调变化和句子韵律。
- [NHK 日本語発音アクセント新辞典](https://www.nhk-book.co.jp/detail/000000113262016.html)：权威音调词典，适合进阶学习者建立标准音意识。

## 词典

- [Weblio 辞書](https://www.weblio.jp/)：日日、日日英、例句和专业词汇覆盖广，适合查细微语义。
- [Jisho.org](https://jisho.org/)：英语界常用日语词典，支持汉字部件、例句和 JLPT 标签。
- [goo辞書](https://dictionary.goo.ne.jp/)：日语母语者常用在线词典，适合训练日文解释阅读能力。

## 阅读输入

- [NHK NEWS WEB EASY](https://www3.nhk.or.jp/news/easy/)：带假名标注的简易新闻，适合 N4 左右开始进行真实阅读。
- [やさしい日本語ニュース](https://www3.nhk.or.jp/news/easy/)：可作为每日泛读素材，建议先读标题，再听音频。

## 语法与考试

- [JLPT 官方样题](https://www.jlpt.jp/e/samples/forlearners.html)：了解题型和难度的首选资料。
- [日本語教育通信](https://www.jpf.go.jp/j/project/japanese/teach/tsushin/)：日本国际交流基金提供的教学与学习文章，适合教师和自学者。

## 推荐使用方法

1. 查新词：先用 Jisho 快速确认意思，再用 Weblio 看日文释义和搭配。
2. 练发音：把动词基本形、ます形、て形输入 OJAD，观察音调是否变化。
3. 做阅读：每天读一篇 NHK Easy News，摘录 3 个词、1 个语法、1 个句型。
4. 备考：每两周做一次 JLPT 官方样题，记录错题原因而不是只记录分数。
