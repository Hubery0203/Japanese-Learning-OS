# N4 学习里程碑

N4 是当前学习路线的下一目标。本里程碑按可验证的原子课程推进，课程顺序是学习设计，不是 JLPT 官方语法清单；JLPT 不发布固定的词汇、汉字和语法项目清单。[官方说明](https://www.jlpt.jp/e/faq/)

## 第一批课程

| 课程 | 目标 | 重点区分 |
|---|---|---|
| L016 | 〜たことがある | 经历；不用于刚发生的单次动作 |
| L017 | 〜てみる | 尝试做某事 |
| L018 | 〜ておく | 事先准备、暂且保持 |
| L019 | 〜てしまう | 完成、遗憾或意外结果 |
| L020 | 〜ことになる | 外部决定或既定安排 |
| L021 | 〜なければならない | 义务；口语缩约形式 |
| L022 | 〜ようと思う | 说话人的计划或意向 |
| L023 | 〜んです | 补充说明、解释背景 |
| L024 | 〜かどうか | 嵌入句中的“是否” |
| L025 | 〜間 / 〜間に | 持续期间与期间内某时点 |
| L026 | 〜そうだ（传闻） | 转述听到的信息，与样态「そうだ」区分 |
| L027 | 〜らしい | 传闻或基于线索的判断 |

## 完成判据

- 每课先独立作答，再查看示例并自评；自评 4–5 分才计入课程完成。
- 完成所有先修课后再解锁下一课。
- 完成 N4 自测并查看分项结果；错题进入本地复习队列。
- 课程完成数来自当前浏览器记录；导出 JSON 可手动备份或迁移。

本里程碑不把题目分数当作 JLPT 官方成绩，也不自动改写历史学习记录。
