## Lesson 022: Particles は / が / を / で / へ / の

### へ (Direction)
Pattern:
- Place + へ + 行きます

Examples:
- 東京へ行きます。
- 東京へ行きたいです。

### で (Place of action)
Pattern:
- Place + で + Action

Example:
- 日本で日本語を勉強します。

### を (Object)
Pattern:
- Object + を + Verb

Examples:
- 寿司を食べます。
- 水を飲みます。

### が (Likes / preference)
Pattern:
- Object + が好きです

Examples:
- 日本語が好きです。
- 日本料理が好きです。
- 寿司が好きです。

### の (Connection)
Example:
- 日本語の勉強

## Lesson 023: Time Words

Vocabulary:
- 毎日（まいにち）: every day
- 来年（らいねん）: next year
- 再来年（さらいねん）: the year after next

Examples:
- 毎日日本語を勉強します。
- 来年東京へ行きたいです。
- 再来年京都へ行きます。

## Lesson 024: Adjectives and Feelings

Vocabulary:
- 難しい（むずかしい）: difficult
- 面白い（おもしろい）: interesting
- 楽しい（たのしい）: fun
- 少し（すこし）: a little

Examples:
- 日本語は少し難しいです。でも、面白いです。
- 日本語の勉強は楽しいです。

Negative:
- 日本語は難しくないです。

## Lesson 025: Ability Expression

Vocabulary:
- 上手（じょうず）: good at
- まだ: still / not yet

Example:
- まだ上手ではありません。
